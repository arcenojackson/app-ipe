Como Solicitar a Exclusão de Sua Conta e Dados

Para solicitar a exclusão de sua conta e todos os dados associados, siga os seguintes passos:

  1. Envie um e-mail para jackson.f205@gmail.com com o assunto "Solicitação de Exclusão de Dados - App IPE"
  2. Informe no e-mail:
    • Seu nome completo
    • Endereço de e-mail associado à conta
    • Confirmação de que deseja excluir permanentemente sua conta e todos os dados
  3. Aguarde a confirmação: Você receberá uma confirmação por e-mail em até 30 dias úteis
  4. Processamento: Após a confirmação, sua conta e dados serão excluídos permanentemente

📧 E-mail para solicitação:

jackson.f205@gmail.com

Dados que Serão Excluídos

Ao solicitar a exclusão, os seguintes dados serão permanentemente removidos:

  • Dados de Conta:
    • Endereço de e-mail
    • Nome do usuário
    • ID de usuário
    • Credenciais de autenticação
  • Dados Criados pelo Usuário:
    • Eventos criados pelo usuário
    • Pessoas cadastradas pelo usuário
    • Músicas adicionadas pelo usuário
  • Dados de Uso:
    • Dados de Analytics (Firebase Analytics)
    • Logs de erros (Firebase Crashlytics)

Período de Retenção

Após a solicitação de exclusão ser confirmada, os dados serão excluídos em até 30 dias úteis.

⚠️ Importante:

  • A exclusão é permanente e irreversível
  • Após a exclusão, você não poderá recuperar seus dados
  • Alguns dados podem ser mantidos conforme exigido por lei (ex: registros fiscais, se aplicável)
  • Dados agregados e anonimizados podem ser mantidos para fins estatísticos

Armazenamento dos Dados

Os dados do App IPE são armazenados nos seguintes serviços:

  • Firebase Authentication: Dados de autenticação e conta
  • Cloud Firestore: Dados do usuário, eventos, pessoas e músicas
  • Firebase Analytics: Dados de uso e analytics
  • Firebase Crashlytics: Logs de erros

Todos os dados são armazenados de forma segura e criptografada nos servidores do Google Firebase.
